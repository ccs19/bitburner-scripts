
augments.json -- Contains structured data of all augments in the game.
This is keyed by augment name. Contains spoilers.
Useful fields for purchasing decision:
1. "factions" -- The factions that must be joined to purchase the augment.
2. "repCost" -- The reputation required to purchase the augment.
3. "moneyCost" -- The money required to purchase the augment.

crime.json -- Contains structured data of all crime in the game.
Currently just an array. Needs more info.
