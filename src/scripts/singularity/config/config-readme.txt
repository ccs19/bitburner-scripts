
config.json allows configuring what to do at any given moment. 
This file is watched for changes and updates current tasks in real time.

currentWorkType -- The work type to perform.
companyWork -- The company work to perform if "currentWorkType" is "companyWork"
factionWork -- The faction work to perform if "currentWorkType" is "factionWork"
crimeWork -- The crim work to perform if "currentWorkType" is "crimeWork"
factionAlwaysJoin -- Factions that are always joined when an invitation is received.
factionNeverJoin -- Factions never joined. Needed?
destroyBitNode -- I don't know what this means. It's some gameplay thing.
backdoorTargets -- Machines to backdoor. Why?
